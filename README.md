# AI Healthcare Network

A full-stack prototype that estimates **heart disease risk** from patient health values and explains the result in simple words.

> **Prototype for learning and demo only.** It uses a public dataset and dummy data. It is **not a medical device** and must not be used for real patient decisions.

---

## Features

- Heart risk prediction using a machine learning model (Logistic Regression vs Random Forest, the better one is saved)
- FastAPI backend with input validation
- React + Tailwind CSS frontend
- Plain-language explanation generated by the Gemini API (backend only, the key is never in the frontend)
- Safe fallback message if Gemini is unavailable
- Clear medical disclaimer on every result

## How to Run

### 1. Train the model
```
cd 1_model
pip install pandas scikit-learn joblib
python train.py
```
This creates `model.pkl` inside `2_backend`.

### 2. Start the backend
```
cd 2_backend
pip install -r requirements.txt
uvicorn main:app --reload
```
Open http://localhost:8000/docs to test the API.

### 3. Start the frontend (in a second terminal)
```
cd 3_frontend
npm install
npm run dev
```
Open http://localhost:5173

### 4. (Optional) Enable Gemini explanations
Create a file `2_backend/.env`:
```
GEMINI_API_KEY=your_key_here
GEMINI_MODEL=your_model_name_here
```
Get a key and the model name from Google AI Studio. **Never commit `.env` to GitHub.** If no key is set, the app still works and shows a simple built-in explanation.

## API

**POST** `/predict`

Request:
```json
{
  "age": 50, "sex": 1, "cp": 0, "trestbps": 130, "chol": 240,
  "fbs": 0, "restecg": 1, "thalach": 150, "exang": 0,
  "oldpeak": 1.0, "slope": 1, "ca": 0, "thal": 2
}
```

Response:
```json
{
  "risk_percent": 52.4,
  "risk_level": "MEDIUM",
  "explanation": "...",
  "disclaimer": "This is a screening aid, not a medical diagnosis. Please consult a doctor."
}
```

Risk levels: LOW (below 35%), MEDIUM (35% to 65%), HIGH (above 65%).

## Limitations

- Trained on a small public dataset, not clinically validated
- Gives a risk estimate only, not a diagnosis
- No login, database or patient record storage yet
- Not compliant with healthcare data laws (such as India's DPDP Act) and not approved for clinical use

---
